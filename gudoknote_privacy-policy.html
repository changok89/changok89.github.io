개인정보처리방침

작성일: 2026년 10월 23일 · 운영자: Changok Kim

출시 준비 단계의 개인정보처리방침 초안입니다. 아래는 계획된 출시 기능을 기준으로 하며, 실제 배포 빌드와 광고 SDK 구성을 확인한 후 시행일과 내용을 확정합니다.

1. 적용 범위와 핵심 원칙

이 방침은 구독장부(GudokNote)의 개인정보 처리 방법을 설명합니다. 구독장부는 사용자가 직접 입력한 정기 구독의 이름, 금액, 결제일을 기록하는 장부입니다. 계정 생성, 운영자 서버에 장부 보관, 자동 클라우드 동기화, 은행·카드·메일·문자 조회를 제공하지 않습니다.

구독 이름, 금액, 메모, 결제일은 운영자나 광고 사업자에게 전송하지 않습니다. 다만 AdMob 광고 제공을 위해 광고 관련 기술 정보가 별도로 처리될 수 있습니다. 로컬 장부라는 말이 앱의 모든 네트워크 통신이 없다는 의미는 아닙니다.

2. 기기 안에서 처리하는 정보

  • 구독 장부: 이름, 분류, 금액, 통화, 주기, 결제일, 체험 종료일, 내가 내는 금액, 상태, 메모, 금액 이력, 결제 스냅샷을 암호화하여 기기에 저장합니다.
  • 사용자가 만든 백업: 비밀번호로 보호된 백업 파일을 사용자가 선택한 위치에 저장할 수 있습니다. 운영자는 그 파일을 받지 않습니다.
  • 설정: 기본 통화, 화면, 알림, 잠금, 광고 개인정보 선택, 광고 중지 보상 만료 시각처럼 기능에 필요한 설정을 기기에 저장할 수 있습니다.

카드 번호와 계좌 번호를 받는 입력란은 두지 않습니다. 운영자는 앱 안의 장부를 원격으로 열람하지 않습니다.

3. 사용 목적

  • 사용자가 입력한 구독의 저장, 수정, 삭제와 이번 달·달력 조회
  • 입력한 결제일과 체험 종료일에 대한 기기 안 알림
  • 사용자가 요청한 CSV 보내기와 암호 백업·복원
  • 선택한 앱 잠금, 광고 제공 및 개인정보 선택 반영

장부 내용을 광고 타기팅, 사용자 프로파일링, 모델 학습에 사용하거나 판매하지 않습니다. 별도의 원격 이용 분석 서비스를 운영하지 않습니다.

4. 권한

알림: 결제일과 체험 종료일 알림을 보낼 때 요청합니다. 거절해도 장부의 입력과 조회는 이용할 수 있습니다.

네트워크: 광고 제공, 광고 개인정보 동의, 외부 지원 페이지에 쓰일 수 있습니다. 장부의 저장과 조회, 백업 파일 생성은 네트워크 연결을 필요로 하지 않도록 설계합니다.

선택적 생체 인증: 앱 잠금을 켠 경우 운영체제 인증을 이용합니다. 지문·얼굴의 원본 정보를 앱이나 운영자가 수집하지 않습니다.

문자, 통화기록, 메일, 연락처, 사진, 위치, 달력, 은행·카드 계정, 알림 접근, 접근성 서비스 권한은 요청하지 않습니다.

5. AdMob과 광고 관련 정보

구독장부는 Google AdMob을 이용해 배너와 보상형 전면 광고를 제공할 수 있습니다. 전면 광고는 기본으로 꺼 두고, 사용하더라도 도움말과 설정 사이의 전환으로 제한하는 방향입니다. Google Mobile Ads SDK는 광고 표시, 측정, 보안, 부정 이용 방지를 위해 IP 주소, 대략적인 위치 추정에 쓰일 수 있는 네트워크 정보, 기기·앱 관련 정보, 광고 상호작용, 진단 정보, 설정과 동의에 따라 기기 또는 광고 식별자 등을 처리할 수 있습니다.

비개인화 광고라도 IP 주소 등 기술 정보의 처리가 완전히 없어지는 것은 아닙니다. 구독 이름, 금액, 통화, 분류, 메모를 광고 SDK에 전달하거나 지출에 맞춘 광고 요청을 구성하지 않습니다.

적용 지역에서는 Google UMP의 동의 화면을 통해 선택을 안내하고 설정에서 광고 개인정보 선택을 다시 열 수 있도록 합니다. 동의 거부나 광고 미제공으로 기본 장부 기능을 제한하지 않습니다. 초기 구성에서는 교차 앱 추적과 IDFA 이용을 하지 않는 방향으로 설계하며, 실제 배포 구성을 변경하면 필요한 고지와 동의 절차를 반영합니다.

광고 관련 정보는 Google 등 광고 서비스 제공자의 인프라에서 처리될 수 있고, 이용자 거주 국가 외에서 처리될 수 있습니다. 보관 기간과 보호 방식은 해당 제공자의 정책 및 적용 법령에 따릅니다. 실제 SDK와 제공자를 확정한 뒤 적용되는 국외 처리 관련 세부 고지를 보완합니다.

  • Google 개인정보처리방침
  • Google 광고 관련 정보 처리
  • Google Mobile Ads SDK 데이터 공개 안내

6. 백업, CSV, 외부 서비스

운영자는 장부를 제3자에게 자동 전송하지 않습니다. 사용자가 보내기를 선택하면 기기에서 CSV 또는 암호 백업 파일을 만들고, 운영체제 공유 화면을 통해 사용자가 선택한 앱이나 저장 위치로 전달합니다.

CSV는 암호화되지 않습니다. 암호 백업 파일은 사용자가 정한 비밀번호 없이 열리지 않도록 설계합니다. 비밀번호를 잊으면 운영자도 복구할 수 없습니다. 외부 이메일, 메신저, 클라우드에 저장한 사본은 해당 서비스의 정책을 따릅니다. 앱에서 원본을 삭제해도 외부 사본은 삭제되지 않습니다. 공유용 임시 파일은 공유에 필요한 기간 후 정리하도록 설계합니다.

지원 이메일을 보내면 이메일 주소와 사용자가 작성한 문의 내용이 운영자와 이메일 서비스에서 처리됩니다. 문의 내용은 문제 해결과 답변에만 사용하고, 처리 완료 후 최대 90일 이내 삭제하는 것을 운영 기준으로 합니다. 법령상 보존 의무가 있는 경우에는 해당 범위와 기간을 따릅니다. 카드 번호, 계좌 번호, 백업 비밀번호, 백업 파일은 문의에 포함하지 않도록 권장합니다.

7. 보관 기간, 삭제, 복구

기기의 장부는 사용자가 삭제하거나 앱 데이터를 제거할 때까지 보관합니다. 개별 삭제와 모든 장부 삭제를 제공합니다. 전체 삭제 시 저장소와 해당 암호화 키를 폐기하도록 설계합니다. 운영자는 서버에 사본을 보관하지 않아 삭제한 장부를 복구해 드릴 수 없습니다.

자동 클라우드 백업은 제공하지 않으며 운영체제 백업에서도 장부와 키를 제외하도록 구성합니다. 앱 제거, 기기 분실·고장, 키 손실, 백업 비밀번호 분실 시 장부를 복구하지 못할 수 있습니다. 필요한 장부는 사용자가 직접 암호 백업으로 보관해야 합니다.

8. 보호 조치

장부 저장소 암호화, 운영체제의 보안 키 저장소를 이용한 키 보호, 비밀번호 기반 백업 파일, 선택적 기기 인증 잠금, 불필요한 권한과 로그 최소화를 적용하는 방향으로 설계합니다. 광고 SDK와 장부 데이터 접근을 분리하며 구독 이름과 금액을 진단 로그에 포함하지 않습니다.

사용자가 외부에 저장한 CSV, 백업 파일, 스크린샷은 앱의 암호화 저장소 보호 범위에 포함되지 않습니다. 잠금이 해제된 기기를 다른 사람이 사용하는 경우도 고려하여 기기 잠금을 사용해 주세요.

9. 사용자의 선택과 권리

앱 안에서 장부 조회·수정·삭제·CSV 보내기·암호 백업, 알림 권한 변경, 선택적 앱 잠금, 광고 개인정보 선택을 관리할 수 있습니다. 운영자가 보관하는 지원 문의 정보의 열람·삭제 등에 관한 요청은 아래 연락처로 보내실 수 있습니다. 운영자는 기기 안의 장부에 접근할 수 없으므로 원격 삭제나 복구는 수행할 수 없습니다.

10. 아동과 금융 기능

구독장부는 아동을 주 대상으로 하지 않습니다. 미성년자 관련 정보 처리 문의는 아래 연락처로 보내 주세요.

이 앱은 금융회사, 결제 대행, 계좌 조회, 대출, 투자, 세무, 신용 조언 서비스가 아닙니다. 구독 해지와 결제를 대신하지 않으며, 입력값과 실제 청구가 일치한다고 보장하지 않습니다.

11. 웹페이지와 방침 변경

이 소개·지원·방침 페이지에는 자체 방문 분석 스크립트나 광고 SDK를 넣지 않습니다. 웹 호스팅 제공자는 페이지 제공과 보안을 위해 접속 관련 기술 정보를 처리할 수 있습니다. 앱에서 기기에만 저장하는 장부와는 별개의 처리입니다.

기능이나 사용 서비스가 변경되면 이 페이지의 작성·시행 정보를 업데이트하고, 필요한 경우 앱 안에서 변경 내용과 추가 선택 절차를 안내합니다.
