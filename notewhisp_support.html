이 페이지는 NoteWhisp로 회의를 녹음하고 회의록을 만드는 중에 도움이 필요할 때 보는 기본 안내입니다.

앱이 하는 일

NoteWhisp는 회의 오디오를 이 폰에 저장합니다. 설정에 private LLM 주소를 넣어 두면, 그 주소에서 받아쓰기와 회의록(요약, 결정, 할 일)을 만듭니다. 완성된 회의록은 앱 안에서 고치고 마크다운으로 공유할 수 있습니다.

연결 방법

  • 설정에서 OpenAI 호환 기본 주소를 입력합니다. 예: https://llm.example.com/v1
  • 받아쓰기 모델 이름과 회의록 모델 이름을 모두 입력합니다.
  • 서버가 키를 요구할 때만 API 키를 입력합니다. 키는 이 폰의 앱 안에 저장됩니다.
  • 주소를 저장하기 전에는 녹음만 되고, 받아쓰기는 시작하지 않습니다.

자주 겪는 문제

  • 녹음이 시작되지 않으면 마이크 권한이 허용되어 있는지 확인해 주세요.
  • 회의록이 만들어지지 않고 연결이 필요하다고 나오면 설정에 주소와 모델 이름이 저장되어 있는지 확인해 주세요.
  • 주소에 연결하지 못하면 http 또는 https로 시작하는지, 폰이 그 서버에 도달할 수 있는지 확인해 주세요. 같은 네트워크의 서버는 주소가 http일 수 있습니다.
  • HTTP 401이 나오면 API 키를 다시 확인해 주세요.
  • 응답이 너무 오래 걸리거나 빈 받아쓰기가 오면 오디오 길이와 서버 상태를 확인한 뒤 같은 녹음으로 다시 시도해 주세요.
  • 광고가 보이지 않으면 네트워크를 확인해 주세요. 불러오지 못한 광고는 빈 칸으로 두지 않습니다. 완성된 회의록을 처음 닫을 때와 녹음 직후에는 전면 광고가 나오지 않습니다.

권장 점검 방법

  • 앱을 완전히 종료한 뒤 다시 실행하기
  • 최신 앱 버전으로 업데이트하기
  • 마이크 권한과 알림 권한 상태 확인하기
  • 네트워크가 private LLM 주소와 연결되는지 확인하기
  • 가져오기에 실패한 파일이 비어 있지 않은 오디오인지 확인하기
