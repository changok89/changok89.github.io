이 페이지는 NoteWhisp로 회의를 녹음하고 회의록을 만드는 중에 도움이 필요할 때 보는 기본 안내입니다.

앱이 하는 일

NoteWhisp는 회의 오디오를 이 폰에 저장합니다. 설정에서 온디바이스 모델을 받으면, 이 폰에서 받아쓰기와 회의록(요약, 결정, 할 일)을 만듭니다. 완성된 회의록은 앱 안에서 고치고 마크다운으로 공유할 수 있습니다.

모델 받기

  • 설정에서 받아쓰기 언어를 고른 뒤 온디바이스 모델을 받습니다. 영어가 기본입니다. 영어는 약 4.4GB이고, 일본어는 약 1.5GB가 더 필요합니다. 한국어, 중국어, 힌디어, 러시아어는 영어와 같은 받아쓰기 모델을 씁니다. 회의 내용은 그 다운로드에 들어가지 않습니다. 실행에는 메모리 12GB 폰이 필요합니다.
  • 받아쓰기 모델과 회의록 모델이 이 폰에 있어야 회의록 작성이 시작됩니다.
  • 주소나 API 키는 입력하지 않습니다.
  • 모델을 받기 전에는 녹음만 되고, 받아쓰기는 시작하지 않습니다.

자주 겪는 문제

  • 녹음이 시작되지 않으면 마이크 권한이 허용되어 있는지 확인해 주세요.
  • 회의록이 만들어지지 않고 모델이 필요하다고 나오면 설정에서 온디바이스 모델을 받아 주세요.
  • 모델 받기가 멈추면 네트워크를 확인한 뒤 같은 버튼을 다시 눌러 주세요. 이미 받은 부분은 이어서 받습니다.
  • 받아쓰기가 비거나 회의록을 읽지 못하면 같은 녹음으로 다시 시도해 주세요. 오디오는 이 폰에 남아 있습니다.
  • 이 기능은 arm64 폰에서 동작합니다. 메모리 12GB 폰이 필요합니다. 메모리가 부족하면 회의록 단계가 실패할 수 있고, 그때도 오디오는 남습니다.
  • 광고가 보이지 않으면 네트워크를 확인해 주세요. 불러오지 못한 광고는 빈 칸으로 두지 않습니다. 완성된 회의록을 처음 닫을 때와 녹음 직후에는 전면 광고가 나오지 않습니다.

권장 점검 방법

  • 앱을 완전히 종료한 뒤 다시 실행하기
  • 최신 앱 버전으로 업데이트하기
  • 마이크 권한과 알림 권한 상태 확인하기
  • 모델 다운로드에 네트워크가 되는지 확인하기
  • 가져오기에 실패한 파일이 비어 있지 않은 오디오인지 확인하기
