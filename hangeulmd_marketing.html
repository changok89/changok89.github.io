HangeulMD

한글 문서를 Markdown으로 바로 바꾸는 가장 실용적인 방법

한글MD는 HWP와 HWPX 문서를 기기 안에서 바로 Markdown으로 변환하고, 변환 결과를 바로 수정하고 미리보고 PDF로 저장할 수 있도록 설계된 오프라인 유틸리티 앱입니다.

서버 업로드 없이 문서를 열고, 변환하고, 다시 정리하는 흐름을 한 앱 안에서 끝낼 수 있습니다.

핵심 가치

한글MD는 복잡한 문서 협업 툴이 아니라, 한글 문서를 Markdown 기반 작업 환경으로 빠르게 옮기기 위한 실용 흐름에 집중합니다.

주요 기능

  • HWP, HWPX 문서를 기기 로컬에서 Markdown으로 변환
  • 변환된 Markdown을 앱 안에서 바로 편집
  • 실시간 미리보기로 변환 결과 확인
  • Markdown 파일 저장 및 PDF 내보내기 지원
  • 최근 변환 문서를 다시 열어 이어서 작업 가능

이 앱이 필요한 사용자

한글 문서를 Obsidian, Notion, GitHub, VS Code, Typora 같은 Markdown 기반 도구로 옮기고 싶은 학생, 연구자, 개발자, 기획자, 프리랜서를 주요 대상으로 합니다.

대표 사용 사례

  • 학교나 회사에서 받은 한글 문서를 Markdown 노트로 정리할 때
  • 보고서 초안을 HWP에서 Markdown 문서로 옮겨 재편집할 때
  • 기존 한글 문서를 PDF나 텍스트 기반 문서로 다시 배포할 때
  • 최근 변환 문서를 다시 열어 이어서 수정하거나 내보낼 때

제품 방향

한글MD는 모바일에서 문서를 빠르게 변환하고 가볍게 수정하는 경험을 우선합니다. 복잡한 계정 체계나 클라우드 저장보다 오프라인 변환, 빠른 실행, 단순한 편집 흐름을 더 중요하게 다룹니다.
