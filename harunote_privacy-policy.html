개인정보처리방침

작성일: 2026년 10월 23일 · 운영자: Changok Kim

출시 준비 단계의 개인정보처리방침 초안입니다. 아래는 계획된 출시 기능을 기준으로 하며, 실제 배포 빌드와 광고 SDK 구성을 확인한 후 시행일과 내용을 확정합니다.

1. 적용 범위와 핵심 원칙

이 방침은 하루수첩(HaruNote)의 개인정보 처리 방법을 설명합니다. 하루수첩은 별도의 혈당계·혈압계에 표시된 수치를 촬영하거나 직접 입력하여 기록하는 도구입니다. 계정 생성, 운영자 서버에 건강 기록 보관, 자동 클라우드 동기화를 제공하지 않습니다.

건강 기록과 촬영 사진은 운영자나 광고 사업자에게 전송하지 않습니다. 다만 AdMob 광고 제공을 위해 광고 관련 기술 정보가 별도로 처리될 수 있습니다. ‘로컬 기록’이 앱의 모든 네트워크 통신이 없다는 의미는 아닙니다.

2. 기기 안에서 처리하는 정보

  • 촬영 이미지: 측정기 화면의 숫자 추출과 사용자의 결과 확인을 위해 메모리에서 일시 처리합니다. 사진 앨범, 앱의 영구 파일 저장소 또는 서버에 보관하지 않습니다.
  • 측정 기록: 혈당 값·단위, 최대혈압·최소혈압·심박수, 측정 날짜·시간·시간대, 식사 구분, 선택한 메모와 입력 방식 등을 암호화하여 기기에 저장합니다.
  • 설정: 화면과 잠금 관련 선택, 광고 개인정보 선택 상태, 광고 중지 보상 만료 시각 등 기능 제공에 필요한 설정을 기기에 저장할 수 있습니다.

운영자는 앱 안의 건강 기록을 원격으로 열람하지 않습니다. 사진은 확인·취소 후 또는 앱이 백그라운드로 이동할 때 처리 버퍼를 해제하도록 설계합니다.

3. 사용 목적

  • 측정기 숫자를 기기 안에서 인식하고 확인할 수 있도록 제공
  • 사용자가 확인한 기록의 저장·수정·삭제와 날짜별 조회
  • 진료 보기와 사용자가 요청한 PDF·CSV 내보내기
  • 선택한 앱 잠금, 광고 제공 및 개인정보 선택 반영

건강 기록이나 사진을 광고 타기팅, 사용자 프로파일링, 모델 학습을 위해 사용하거나 판매하지 않습니다. 별도의 원격 이용 분석·건강 기록 분석 서비스를 운영하지 않습니다.

4. 권한

카메라: 측정기 화면을 촬영할 때 요청합니다. 거절해도 직접 입력을 이용할 수 있습니다.

네트워크: 광고 제공, 광고 개인정보 동의 및 외부 지원 페이지 이용에 쓰일 수 있습니다. 기록의 인식·저장·조회 자체는 네트워크 연결을 필요로 하지 않도록 설계합니다.

선택적 생체 인증: 앱 잠금을 켠 경우 운영체제 인증을 이용합니다. 지문·얼굴의 원본 정보를 앱이나 운영자가 수집하지 않습니다.

사진 보관함 전체, 연락처, 위치, Google Calendar·Apple Calendar, HealthKit·Health Connect 접근 권한은 요청하지 않습니다.

5. AdMob과 광고 관련 정보

하루수첩은 Google AdMob을 이용해 배너, 전면 및 보상형 전면 광고를 제공할 수 있습니다. Google Mobile Ads SDK는 광고 표시·측정·보안·부정 이용 방지를 위해 IP 주소, 대략적인 위치 추정에 쓰일 수 있는 네트워크 정보, 기기·앱 관련 정보, 광고 상호작용, 진단 정보, 설정과 동의에 따라 기기 또는 광고 식별자 등을 처리할 수 있습니다.

비개인화 광고라도 IP 주소 등 기술 정보의 처리가 완전히 없어지는 것은 아닙니다. 건강 수치, 메모, 식사 구분, 촬영 이미지, OCR 원문을 광고 SDK에 전달하거나 건강 상태에 따른 광고 요청을 구성하지 않습니다.

적용 지역에서는 Google UMP의 동의 화면을 통해 선택을 안내하고 설정에서 광고 개인정보 선택을 다시 열 수 있도록 합니다. 동의 거부나 광고 미제공으로 기본 기록 기능을 제한하지 않습니다. 초기 구성에서는 교차 앱 추적과 IDFA 이용을 하지 않는 방향으로 설계하며, 실제 배포 구성을 변경하면 필요한 고지와 동의 절차를 반영합니다.

광고 관련 정보는 Google 등 광고 서비스 제공자의 인프라에서 처리될 수 있고, 이용자 거주 국가 외에서 처리될 수 있습니다. 보관 기간과 보호 방식은 해당 제공자의 정책 및 적용 법령에 따릅니다. 실제 SDK와 제공자를 확정한 뒤 적용되는 국외 처리 관련 세부 고지를 보완합니다.

  • Google 개인정보처리방침
  • Google 광고 관련 정보 처리
  • Google Mobile Ads SDK 데이터 공개 안내

6. 공유·내보내기와 외부 서비스

운영자는 건강 기록과 사진을 제3자에게 자동 전송하지 않습니다. 사용자가 내보내기를 선택하면 기기에서 PDF·CSV 파일을 생성하고 운영체제 공유 화면을 통해 사용자가 선택한 앱이나 저장 위치로 전달합니다.

내보낸 PDF·CSV는 암호화되지 않습니다. 외부 이메일·메신저·클라우드 등에 저장한 사본은 해당 서비스의 정책을 따릅니다. 앱에서 원본을 삭제해도 외부 사본은 삭제되지 않습니다. 공유용 임시 파일은 공유에 필요한 기간 후 정리하도록 설계합니다.

지원 이메일을 보내면 이메일 주소와 사용자가 작성한 문의 내용이 운영자와 이메일 서비스에서 처리됩니다. 문의 내용은 문제 해결과 답변에만 사용하고, 처리 완료 후 최대 90일 이내 삭제하는 것을 운영 기준으로 합니다. 법령상 보존 의무가 있는 경우에는 해당 범위와 기간을 따릅니다. 건강 정보나 사진을 문의에 포함하지 않도록 권장합니다.

7. 보관 기간·삭제·복구

기기의 기록은 사용자가 삭제하거나 앱 데이터를 제거할 때까지 보관합니다. 개별 기록 삭제와 모든 기록 삭제 기능을 제공합니다. 전체 삭제 시 기록 저장소와 해당 암호화 키를 폐기하도록 설계합니다. 운영자는 서버에 사본을 보관하지 않아 삭제한 기록을 복구해 드릴 수 없습니다.

자동 클라우드 백업은 제공하지 않으며 운영체제 백업에서도 민감한 기록과 키를 제외하도록 구성합니다. 앱 제거, 기기 분실·고장, 키 손실 시 기록을 복구하지 못할 수 있습니다. 필요한 기록은 사용자가 직접 내보내 주세요. 초기 버전의 PDF·CSV는 열람용이며 앱으로 다시 가져오는 복원 기능은 제공하지 않습니다.

8. 보호 조치

기록 저장소 암호화, 운영체제의 보안 키 저장소를 이용한 키 보호, 선택적 기기 인증 잠금, 불필요한 권한과 로그 최소화를 적용하는 방향으로 설계합니다. 광고 SDK와 기록 데이터 접근을 분리하며 건강 기록을 진단 로그에 포함하지 않습니다.

사용자가 외부에 저장한 파일이나 직접 촬영한 스크린샷은 앱의 암호화 저장소 보호 범위에 포함되지 않습니다. 잠금이 해제된 기기를 다른 사람이 사용하는 경우도 고려하여 기기 잠금을 사용해 주세요.

9. 사용자의 선택과 권리

앱 안에서 기록 조회·수정·삭제·내보내기, 카메라 권한 변경, 선택적 앱 잠금, 광고 개인정보 선택을 관리할 수 있습니다. 운영자가 보관하는 지원 문의 정보의 열람·삭제 등에 관한 요청은 아래 연락처로 보내실 수 있습니다. 운영자는 기기 안의 기록에 접근할 수 없으므로 원격 삭제나 복구는 수행할 수 없습니다.

10. 아동과 의료 기능

하루수첩은 주로 성인과 고령층을 위한 개인 기록 앱이며 아동을 주 대상으로 하지 않습니다. 미성년자 관련 정보 처리 문의는 아래 연락처로 보내 주세요.

이 앱은 의료 기기가 아니며 어떠한 의학적 상태도 진단, 처치, 치료 또는 예방하지 않습니다. 의학적 조언, 진단 또는 치료는 의료 전문가와 상담하세요.

11. 웹페이지와 방침 변경

이 소개·지원·방침 페이지에는 자체 방문 분석 스크립트나 광고 SDK를 넣지 않습니다. 웹 호스팅 제공자는 페이지 제공·보안을 위해 접속 관련 기술 정보를 처리할 수 있습니다. 앱에서 기기에만 저장하는 건강 기록과는 별개의 처리입니다.

기능이나 사용 서비스가 변경되면 이 페이지의 작성·시행 정보를 업데이트하고, 필요한 경우 앱 안에서 변경 내용과 추가 선택 절차를 안내합니다.
