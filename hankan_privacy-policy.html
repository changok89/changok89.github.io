개인정보처리방침

시행일: 2026년 10월 25일 · 운영자: Changok Kim

1. 적용 범위

이 방침은 아이패드 앱 한칸(Hankan, 번들 ID com.alan.hankan)이 정보를 다루는 방식을 설명합니다. 한칸은 글자를 기억해 쓰도록 돕는 학습 앱입니다.

계정, 학습 서버, 광고 SDK, 분석 SDK가 없습니다. 필기, 오답, 학습한 단어, 가져온 학습 데이터를 운영자의 서버나 외부 AI API로 보내지 않습니다. 필기 인식과 글자 읽기 음성은 기기 안에서 처리합니다.

2. 기기 안에서 처리하는 정보

  • 학습 기록: 고른 과정, 글자와 단어의 복습 상태, 제출 결과, 화면 언어와 학습 설정을 기기에 저장합니다.
  • 필기: 필기 원본은 기본으로 저장하지 않습니다. 결과에서 보관을 고른 오답만 이 기기에 남길 수 있습니다.
  • 가져온 학습 데이터: 사용자가 고른 엑셀, CSV, JSON 파일로 추가한 과정과 그 학습 기록을 기기에 저장합니다.
  • 내보내기 파일: 사용자가 내보내기를 실행하면 학습 기록 파일을 만들고, 시스템 공유 화면에서 사용자가 고른 위치로 보냅니다. 운영자는 그 파일을 받지 않습니다.

이름, 이메일, 전화번호, 위치, 연락처, 사진은 받지 않습니다. 운영자는 앱 안의 학습 기록을 원격으로 열람하지 않습니다.

3. 사용 목적

  • 오늘 배울 글자와 복습 순서를 기기에 구성
  • 가리고 쓴 필기를 기기 안에서 확인하고, 확신이 없으면 사용자에게 직접 확인을 요청
  • 사용자가 요청한 학습 데이터 추가, 기록 내보내기, 복원, 삭제

학습 내용을 광고, 프로파일링, 모델 학습에 쓰거나 판매하지 않습니다. 별도의 이용 분석 서비스를 운영하지 않습니다.

4. 권한

카메라, 마이크, 사진, 위치, 연락처, 추적 권한을 요청하지 않습니다. 글자를 읽어 주는 기능은 기기의 음성 합성입니다. 사용자의 목소리를 녹음하지 않습니다.

학습 데이터를 가져오거나 기록을 내보낼 때는 아이패드 시스템의 파일 선택과 공유 화면을 사용합니다. 사용자가 고른 파일만 읽습니다.

5. 백업과 다른 기기

학습 기록은 앱의 저장 공간에 있으며, 사용자가 켠 아이패드 백업(컴퓨터 백업 또는 iCloud 기기 백업)에 포함될 수 있습니다. 이것은 계정으로 한칸 서버에 동기화하는 기능이 아닙니다. 운영자는 그 백업을 열람하거나 다른 기기로 옮겨 드리지 못합니다.

앱을 지우거나, 백업 없이 기기를 바꾸거나, 내보내기 파일을 잃으면 학습 기록을 복구하지 못할 수 있습니다. 필요한 기록은 사용자가 직접 내보내 보관해야 합니다. 공유한 파일은 받은 쪽 앱과 저장 위치의 정책을 따릅니다. 앱에서 원본을 지워도 밖에 저장한 사본은 지워지지 않습니다.

6. 보관과 삭제

기기의 기록은 사용자가 지우거나 앱을 제거할 때까지 남습니다. 개별 필기 삭제와 모든 학습 기록 삭제를 제공합니다. 운영자는 서버에 사본을 두지 않으므로 삭제한 기록을 복구해 드리지 못합니다.

7. 지원 문의

지원 이메일을 보내면 이메일 주소와 적은 내용이 운영자와 이메일 서비스에서 처리됩니다. 문의 답변에만 사용하고, 처리가 끝난 뒤 90일 안에 지우는 것을 기준으로 합니다. 법령상 더 두어야 하는 경우에는 그 기간을 따릅니다.

학습 기록 파일, 필기 이미지, 다른 서비스의 비밀번호는 문의에 넣지 않아도 됩니다.

8. 아동

한칸은 아동을 대상으로 가입을 받거나 연령을 수집하지 않습니다. 계정 자체가 없습니다. 아동의 기기 사용은 보호자가 정해 주세요. 관련 문의는 아래 연락처로 보내실 수 있습니다.

9. 이 웹페이지

소개, 도움말, 이 방침 페이지에는 방문 분석 스크립트와 광고를 넣지 않습니다. 페이지를 제공하는 GitHub Pages가 접속에 필요한 기술 정보를 처리할 수 있습니다. 그것은 아이패드 안에만 있는 학습 기록과는 별개입니다.

10. 변경과 연락처

광고 SDK를 넣거나 기록을 기기 밖으로 보내는 기능이 생기면, 그 빌드를 배포하기 전에 이 페이지의 시행일과 내용을 바꿉니다.
